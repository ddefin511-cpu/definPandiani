# Student Insight Dashboard — Merah × Hijau Tua

Dashboard statistik deskriptif berbasis Streamlit dengan tema merah dan hijau tua.

## File utama
- `app.py` — dashboard
- `latihan1.csv` — dataset
- `requirements.txt` — library yang dibutuhkan

## Menjalankan secara lokal
Buka CMD di folder ini, lalu jalankan:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Buka `http://localhost:8501` jika browser tidak terbuka otomatis.

Untuk GitHub, upload hanya tiga file utama di atas; jangan upload folder `.venv`.
